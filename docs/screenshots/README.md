# Ekran görüntüleri / Screenshots

README'deki yer tutucular bu klasördeki dosyalara işaret eder:

- `host-lobby.png` — ana ekran lobisi (QR + oyuncular), 1920×1080
- `host-results.png` — kazanan ekranı, 1920×1080
- `phone-swipe.png` — telefonda kart destesi, 390×844
- `demo.gif` — kısa akış (katılım → kaydırma → açıklama), ≤ 8 MB

Nasıl çekilir: `npm run dev`, ana ekranı 1920×1080 pencerede açın; telefon görünümü için geliştirici araçlarında cihaz emülasyonu kullanın. GIF için Peek, ScreenToGif veya macOS `Cmd+Shift+5`. Afişli görüntüler için `TMDB_API_KEY` gerekir.
